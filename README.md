# 🍕 Pizza Crazy Dashboard

Professional analytics dashboard for Pizza Crazy pizzeria built with vanilla JavaScript, CSS3, and modern web standards.

## 🌟 Features

- **Real-time Analytics** - KPI cards with animated counters
- **Data Visualization** - Top 10 products, heatmaps, donut charts, timelines
- **Dark Theme** - Premium dark UI with red accent
- **Responsive Design** - Mobile-first
- **No Dependencies** - Pure vanilla JavaScript
- **localStorage Integration** - Orders persist in browser

## 📁 Project Structure

```
pizza-crazy-dashboard/
├── index.html
├── css/styles.css
├── js/main.js
├── docs/DESIGN.md
├── README.md
└── package.json
```

## 🚀 Quick Start

1. Clone: `git clone https://github.com/ndanx/pizza-crazy-dashboard.git`
2. Open `index.html` in browser
3. Done! No build process needed.

## 📊 Data Structure

Orders stored in `localStorage['pizza_crazy_orders_v1']`

## 🔄 Auto-Refresh

- Live feed: Every 30 seconds
- Status: Every 1 second

## 🎨 Design System

- **Primary Accent**: `#e63946` (Red)
- **Dark Background**: `#0a0a0a`
- **Typography**: system-ui, -apple-system, sans-serif
